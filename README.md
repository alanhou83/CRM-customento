# Customento CRM

纯HTML/JavaScript的CRM/ERP试跑应用，保留PWA。主页面为`crm-v5_final_5.html`，部署路径`/CRM-customento/`。

公开仓库只放代码；业务快照和图片放独立私有数据仓库。新设备没有内置业务数据，需在同步设置中授权读取；旧浏览器数据保留。

## 个人同步试跑

- 全局“同步”按钮可进入设置，连接本人有权访问的私有数据仓库。
- 细粒度GitHub令牌只授予指定数据仓库Contents读写及必需Metadata读取，设置有效期，仅填本人CRM页面；不要发聊天、提交仓库或写入URL。
- 令牌默认仅当前页面有效；可勾选“记住此设备”保存到本人浏览器，重新打开自动恢复授权。取消授权删除本机令牌，保留业务数据；令牌不进入备份或云端快照。当前页授权后可前台定时同步。关闭上传不保证完成。
- 首次连接先备份，确认以云端基准接续；本机已有图片时先核对映射，不自动覆盖。
- 图片详情上限300KB、缩略图60KB；设置提供含图片的完整备份。

数据交换规则见[格式与同步约定](docs/data-sync-contract.md)。开发及验证见[AGENTS.md](AGENTS.md)。

当前GitHub方式用于个人过渡试跑，不能当作已实现多人权限隔离或高并发数据库。CBOS增量任务需要另行配置，格式支持不等于自动任务已启用。
